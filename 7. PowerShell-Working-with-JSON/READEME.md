# PowerShell Working with JSON

This project demonstrates how to use PowerShell to load, query, modify, and export JSON data. It uses fictional student data to practice structured data handling and CSV export.

## Skills Demonstrated

- PowerShell scripting
- JSON data processing
- Object querying
- Data modification
- CSV export
- File organization

## Tools Used

- PowerShell
- Visual Studio Code
- Windows
- GitHub
